Put Holdfast in front of a real repository.

  1. Sign in with GitHub. Holdfast asks for one permission: to add and remove webhooks on your repositories. It can't read or change your code.
  2. Pick a repository. Holdfast adds itself as a webhook. GitHub sends a test "ping" straight away, so you'll see the first message arrive within seconds.
  3. Choose where messages go. Your own app's address, or Holdfast's built-in test app, which you can make fail on purpose.

Stripe

Using Stripe?

After you sign in, you can connect Stripe by hand: paste the address Holdfast gives you into Stripe's webhook settings, and Stripe's signing secret back into Holdfast.

One-click "Sign in with Stripe" needs a Stripe platform account, which this project doesn't have yet. We'd rather say so than pretend.

What Holdfast keeps

Messages for three days, so you can resend them. Your GitHub token, encrypted. Nothing is sent to an AI company: Gemma runs on the same server.
